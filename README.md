# 幹話日曆禮物盒

交換禮物用的拆禮物網頁（手機版）。流程：搖盒子 → 拉緞帶 → 撕包裝紙 → 掀盒蓋 → 撕 2027 日曆（可按住快轉）→ 撕完後拿到「提貨券」，簽名、蓋章。

## 檔案

- `index.html`：整個網頁（樣式、程式、文案都在裡面）
- `assets/`：實品照片（看開卡其、放空天藍、摸魚薄荷）

## 要改的地方

打開 `index.html`，搜尋 `CONFIG`：

```js
const CONFIG = {
  to:   '抽到我的你',        // 禮物吊牌上的「給」
  from: '一個也很厭世的人',   // 吊牌上的「來自」、最後留言的署名
  color:'khaki',            // khaki 看開卡其 ｜ blue 放空天藍 ｜ mint 摸魚薄荷
};
```

如果自己架站（例如 Netlify、GitHub Pages），也可以用網址參數，不用改檔案：

```
index.html?to=小明&from=阿德&color=mint
```

## 小提醒

- iPhone 要把側邊的靜音鍵關掉，才聽得到聲音。
- 日曆上的每日一句是另外寫的，不是實體日曆的內容；實品照片取自商品頁。
- 簽過名之後，同一支手機再打開會出現「直接看提貨券」。
