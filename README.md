# 給你的禮物

交換禮物用的拆禮物網頁（手機版）。網址：https://mund99.github.io/calendar-gift/

流程：搖盒子 → 拉緞帶 → 撕包裝紙 → 掀盒蓋 → 撕 2027 日曆（可按住快轉）→ 撕完後拿到「提貨券」，簽名、蓋章。

## 檔案

- `index.html`：整個網頁（樣式、程式、文案都在裡面）
- `assets/blue.jpg`：實品照片（放空天藍）

## 改吊牌上的名字

打開 `index.html`，搜尋 `CONFIG`：

```js
const CONFIG = {
  to: '抽到我的你',   // 禮物吊牌上的「給」
};
```

也可以直接用網址參數，不用改檔案：

```
https://mund99.github.io/calendar-gift/?to=小明
```

## 小提醒

- 背景音樂：拆禮物、撕日曆時是八音盒版〈Jingle Bells〉；撕完一年換成〈友誼萬歲〉，蓋章時再完整播一次。iPhone 開著靜音模式也會出聲，右上角喇叭可以關掉。
- iPhone 的 Safari 不支援一般的震動；這裡用 iOS 18 的開關觸覺回饋，在點擊、放開手指時會「噠」一下。
- 日曆上的每日一句是另外寫的，不是實體日曆的內容；實品照片取自商品頁。
- 簽過名之後，同一支手機再打開會出現「直接看提貨券」。
- 改完 `index.html` 後 commit 並 push，GitHub Pages 約一分鐘後更新。
